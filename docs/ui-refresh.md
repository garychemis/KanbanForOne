# 桌面 UI 规范

本次更新覆盖看板、归档、日历、人工时、设计条件、备份、设置、关于，以及任务、备忘、附件和各业务弹窗。

## 视觉规范

| 用途 | 颜色 / 尺寸 |
| --- | --- |
| 工作区底色 | `#F1F3EF` |
| 内容表面 | `#FDFDF9` |
| 主要文字 | `#283D38` |
| 次要文字 | `#65716C` |
| 强调色 | `#426D5E` |
| 淡色边框 | `#DEE4DD`，1 DIP |
| 选中背景 | `#E3EDE9` |
| 危险操作 | `#A34F59`，配淡玫瑰色背景 |
| 页面边距 | 24 DIP |
| 控件 / 面板 / 窗体圆角 | 6 / 10 / 12 DIP |

统一资源位于 `Styles/KanbanTheme.xaml`；滚动条、工具提示、原生日历和菜单的基础样式位于 `Styles/ModernControls.xaml`。任务、人工时、设计条件的外部卡片采用淡主题底色与主题色细边框，详情内容保持浅灰底 `#F3F4F2`，不使用紫色。备忘录延续黄色便签样式。

### 任务与模块卡片配色

| 状态 / 模块 | 外部卡片淡底色 | 主题边框 | 侧条 / 悬停强调 |
| --- | --- | --- | --- |
| 待办 · 灰 | `#FDFCF7` | `#B9BDB7` | `#8D9289` |
| 进行中 · 蓝 | `#EEF6F8` | `#9EB9C2` | `#548698` |
| 卡住 · 红 | `#FAEEEC` | `#D1A7A1` | `#AE6D66` |
| 完成 · 绿 | `#F1F6EF` | `#A7BFAF` | `#58876D` |
| 人工时 · 赭金 | `#F8F5EF` | `#C5B08D` | `#9A7848` |
| 设计条件归档 · 青绿 | `#F1F7F5` | `#9DBEBA` | `#4F8781` |

外部卡片与日历卡片采用上表淡底色，边框为 1 DIP，悬停加强主题色轮廓，底色保持不变。任务保留 3 DIP 状态侧条；人工时汇总与设计条件归档的外部面板、统计卡使用对应模块淡底色。任务详情、人工时详情及设计条件详情内容卡继续使用灰底 `#F3F4F2`；详情状态标签使用独立灰底资源，避免受到外部卡片配色影响。按钮使用较深的模块主题色保证小字清晰；危险操作与优先级保留各自的语义色。

备忘录底色 `#FFF5CF`、边框 `#E5D9A8`、悬停边框 `#C5B16A`，标题及辅助文字分别为 `#514620`、`#776A3B`。

## 空间与交互

- 主窗体继续采用无边框结构。56 DIP 顶栏负责导航和窗口操作，搜索与日期筛选使用独立工具栏。
- 看板五列等宽分配；宽屏自动伸展，窄屏提供横向滚动。每列高度适配视口，长列表继续使用虚拟化和独立滚动。
- 日历六周随内容区高度分配，详情列限制合理宽度；小窗不再因固定单元格高度裁切最后一周。
- 卡片取消常驻阴影，悬停仍有轻微反馈；键盘焦点保留可见标记。
- 任务与模块卡片使用主题色细边框，与列容器形成轻微层次；统计面板不设常驻阴影。保留任务卡片的 3 DIP 状态色条，完成卡片继续使用弱化文字及删除线。
- 看板和归档列内的空状态采用透明、无边框样式，避免与真实卡片竞争；其他页面的空状态保留原有容器样式。
- 弹窗使用统一输入框底色、淡边框和主要操作颜色。任务附件列表最高可展示 192 DIP，超出后滚动。

## 验证

执行 `dotnet test KanbanForOne.sln -c Release`。UI 冒烟测试需要 Windows 桌面会话，使用测试输出目录的独立数据库。

UI 测试覆盖 1100×720、1512×900、1920×900 的八个页面，以及窗口操作按钮边界、宽屏列宽、窄屏横向滚动、编辑弹窗、下拉选择和日期弹出层。

可设置环境变量 `KANBAN_UI_PREVIEW_DIR` 后运行 `UiSmokeTests`，保存测试数据下的页面 PNG；本地预览目录 `artifacts/ui-refresh/` 已加入忽略规则。截图等待弹窗动画完成后再渲染。
