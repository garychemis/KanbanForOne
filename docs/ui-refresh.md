# 桌面 UI 规范

本次更新覆盖看板、归档、日历、人工时、设计条件、备份、设置、关于，以及任务、备忘、附件和各业务弹窗。

## 视觉规范

| 用途 | 颜色 / 尺寸 |
| --- | --- |
| 工作区底色 | `#F1F3EF` |
| 内容表面 | `#FDFDF9` |
| 主要文字 | `#283D38` |
| 次要文字 | `#65716C` |
| 强调色 | `#426D5E` |
| 淡色边框 | `#DEE4DD`，1 DIP |
| 选中背景 | `#E3EDE9` |
| 危险操作 | `#A34F59`，配淡玫瑰色背景 |
| 页面边距 | 24 DIP |
| 控件 / 面板 / 窗体圆角 | 6 / 10 / 12 DIP |

当前配色作为亮色主题保留；亮色和暗色的配对资源分别位于 `Styles/LightPalette.xaml`、`Styles/DarkPalette.xaml`，公共样式位于 `Styles/KanbanTheme.xaml`。滚动条、工具提示、原生日历和菜单的基础样式位于 `Styles/ModernControls.xaml`。除“暗色用途”表外，本文颜色表描述亮色主题；暗色主题保留各状态和模块的颜色含义，调整背景、边框与文字对比度。

暗色采用石墨深灰层级，减少大面积色偏；雾蓝用于交互，暖白用于文字。状态色和模块色使用少量低饱和灰蓝、灰绿、香槟金及灰玫瑰。

主文字与卡片表面对比为 11.19:1，次文字为 6.73:1；主按钮白字在普通、悬停、按下状态均高于 4.5:1。日期、月份和年份网格以独立的 2 DIP 内描边指示键盘焦点，与选中背景及“今天”边框分开。

顶部工具栏的太阳/月亮按钮可即时切换主题；设置页的“外观主题”也可直接选择亮色或暗色。首次启动默认亮色，选择保存在 `data/ui-settings.json`，重启后恢复。主题变化无需重新加载页面或关闭编辑窗口。新颜色应加入两份同键色板；XAML 使用 `DynamicResource`，代码生成的内容使用 `ThemeService.GetBrush` 获取共享画刷，以便已经显示的文字与背景同步更新。

外部卡片与日历卡片采用上表淡底色，边框为 1 DIP，悬停加强主题色轮廓，底色保持不变。任务保留 3 DIP 状态侧条；人工时汇总与设计条件归档的外部面板、统计卡使用对应模块淡底色。任务详情、人工时详情及设计条件详情内容卡继续使用灰底 `#F3F4F2`；详情状态标签使用独立灰底资源，避免受到外部卡片配色影响。按钮使用较深的模块主题色保证小字清晰；危险操作与优先级保留各自的语义色。

备忘录底色 `#FFF5CF`、边框 `#E5D9A8`、悬停边框 `#C5B16A`，标题及辅助文字分别为 `#514620`、`#776A3B`。

## 空间与交互

- 主窗体继续采用无边框结构。56 DIP 顶栏负责导航和窗口操作，搜索与日期筛选使用独立工具栏。
- 看板五列等宽分配；宽屏自动伸展，窄屏提供横向滚动。每列高度适配视口，长列表继续使用虚拟化和独立滚动。
- 日历六周在默认状态下随内容区高度均分，详情列限制合理宽度。月格内完成任务展开四行预览时所在周自动增高，超出视口时支持纵向滚动，移开后恢复；其他状态的月格任务保留原有标题与日期范围标记。
- 卡片取消常驻阴影，悬停仍有轻微反馈；键盘焦点保留可见标记。
- 待办、进行中、卡住恢复原卡片布局：看板常驻显示正文预览、日期、优先级、超期提示、附件数及标签；归档沿用原紧凑布局。日历当天任务恢复标题、日期和状态，列表恢复日期、正文预览、状态和优先级；人工时与设计条件卡片恢复原常驻信息。
- 仅完成任务和备忘录默认只显示标题，悬停后按内容自动增加高度，详情最多显示四个视觉行（包括自动换行）；移开后恢复标题高度。空详情不占用空白预览区。任务状态改变时，同一卡片立即切换对应展示方式。
- 任务与模块卡片使用主题色细边框，与列容器形成轻微层次；统计面板不设常驻阴影。保留任务卡片的 3 DIP 状态色条，完成卡片继续使用弱化文字及删除线。
- 看板和归档列内的空状态采用透明、无边框样式，避免与真实卡片竞争；其他页面的空状态保留原有容器样式。
- 弹窗使用统一输入框底色、淡边框和主要操作颜色。任务附件列表最高可展示 192 DIP，超出后滚动。

## 验证

执行 `dotnet test KanbanForOne.sln -c Release`。UI 冒烟测试需要 Windows 桌面会话，使用测试输出目录的独立数据库。

UI 测试覆盖 1100×720、1512×900、1920×900 的八个页面，以及窗口操作按钮边界、宽屏列宽、窄屏横向滚动、编辑弹窗、下拉选择和日期弹出层。主题验证覆盖亮暗往返切换、既有画刷与转换器输出的即时更新、暗色页面和弹窗渲染；卡片验证覆盖未完成任务常驻内容及悬停高度不变、状态往返切换、完成任务与备忘录的收起／展开、四行上限与空详情。

可设置环境变量 `KANBAN_UI_PREVIEW_DIR` 后运行 `UiSmokeTests`，保存测试数据下的页面 PNG；本地预览目录 `artifacts/ui-refresh/` 已加入忽略规则。详情截图等待实际内容容器可见、透明度为 1 且动画结束，并检查标题、Markdown、标签、附件和操作按钮后再渲染。UI 测试手动加载生产资源并创建唯一窗口，完整 App 启动流程另由隔离进程探针验证。

在 Windows 桌面会话中运行 `KanbanForOne.Tests/Probes/Run-ThemeColdStart.ps1 -VerifyPointer`，可验证保存暗色后在新进程首次渲染时恢复，以及真实鼠标悬停、点击、日历滚动、拖拽取消、日期键盘确认／取消和文本框原生右键菜单。探针只使用独立目录中的测试数据，正式应用正在运行时会拒绝启动；结束后恢复指针及前台窗口。结果 JSON 与首屏截图默认输出到 `artifacts/ui-refresh/theme-hover/cold-start/`。
