# 设计条件图纸 DataGrid 美化设计

## 目标

将设计条件详情弹窗中的图纸明细表改为已确认的“方案 A：柔和卡片式”，提升表头、数据行和删除操作的层级感，同时保持现有数据绑定、编辑、校验和键盘操作不变。

## 视觉规格

- 保留现有“条件图纸”外层卡片和顶部统计、添加规格按钮。
- DataGrid 外增加圆角为 10 的独立表格容器，背景使用现有浅色表面色，边框使用设计条件模块边框色，并裁剪内部表头与行背景。
- 表头高度 38，使用比外层背景略深的浅绿色，文字保持 11px、半粗体、三列居中。
- 数据行高度 42，奇偶行采用白色和极浅绿色交替背景；悬停使用模块浅绿色，选中使用更明显的浅绿色。
- 单元格只保留横向分隔线，不增加竖向网格线；键盘焦点使用主题色细边框反馈。
- 删除按钮改为浅红色背景、透明边框的轻量按钮，悬停和按下时逐级加深；文字始终保持可读。
- 表格空白区域保持统一浅色背景，不显示多余说明文字。

## 技术边界

- 主要修改 `DesignConditionControlStyles.xaml`，新增局部画刷、表格容器样式和删除按钮样式。
- `DesignConditionEditorDialog.xaml` 只负责增加圆角容器、启用交替行并引用删除按钮样式。
- 不修改 ViewModel、数据模型、数据库和命令绑定。
- 样式只通过具名资源应用到该图纸 DataGrid，不影响项目内其他 DataGrid。

## 验证

- UI 冒烟测试验证新增资源、交替行设置和样式引用存在。
- Release 配置执行完整测试与格式检查。
- 启动应用检查普通、悬停、选中、编辑和删除按钮状态，确认圆角裁剪及居中布局。
