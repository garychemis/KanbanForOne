# 设计条件折 A1 统计与固定图幅设计

## 目标

设计条件归档仅允许选择固定的九种图幅，并根据每种图幅的折 A1 系数实时计算折 A1 数量。折 A1 不写入数据库，只在运行时和 Excel 导出时计算。

## 固定图幅与换算系数

图幅必须按以下顺序显示，且编辑弹窗中的图幅 `ComboBox` 不允许输入自定义值：

| 图幅 | 折 A1 系数 |
| --- | ---: |
| A4 | 0.125 |
| A3 | 0.25 |
| A2 | 0.5 |
| A1 | 1 |
| A1+0.25 | 1.25 |
| A1+0.5 | 1.5 |
| A0 | 2 |
| A0+0.25 | 2.5 |
| A0+0.5 | 3 |

单条设计条件的折 A1 数量按下式计算：

`折 A1 = Σ（图幅数量 × 对应图幅的折 A1 系数）`

计算使用 `decimal`，最大精度为三位小数，不使用二进制浮点数，也不进行人为舍入。Excel 中使用最多三位小数的数值格式，整数不显示无意义的小数尾零。

## 运行时模型

新增一个集中管理固定图幅及换算系数的运行时定义。编辑器候选项、合法性判断和折 A1 计算均调用同一份定义，避免界面与导出口径不一致。

数据库结构保持不变：

- `DrawingSize` 仍保存图幅字符串；
- `DrawingCounts` 仍保存对应数量字符串；
- `DrawingCount` 仍保存总条件张数；
- 不新增折 A1 字段，不升级设计条件数据库版本。

现有动态 `DrawingSize` 选项不再决定图幅下拉框内容。保存设计条件时也不再把图幅写入动态选项表；历史选项记录可保留在数据库中，但不会显示，也不会参与换算。

## 编辑界面和历史数据兼容

图幅编辑控件改为不可编辑的 `ComboBox`，仅显示固定九项。新建记录和新增规格仍保留当前默认数量 `1` 的行为。

打开历史记录时逐项检查图幅：

- 合法图幅正常显示；
- 不在固定九项中的图幅在编辑界面中显示为空；
- 对应数量保留，便于用户只重新选择图幅；
- 弹窗显示明确提示，至少包含记录名称和无法识别的原图幅；
- 仅打开记录不会修改数据库；只有用户重新选择合法图幅并点击保存后，才覆盖原数据；
- 未修正空图幅时，现有保存校验阻止保存。

主列表仍可显示数据库中的历史图幅摘要。非法历史值不会在后台被静默清除，确保用户取消编辑时原数据完整保留。

## Excel 导出

导出范围保持为当前筛选后的设计条件集合。显示保存文件对话框之前，对该集合执行完整预检查：

- 每条记录的图幅与数量必须能够按现有编解码规则解析；
- 每个图幅必须存在于固定换算表；
- 任意记录不满足条件时，中断整个导出，不创建 Excel 文件；
- 提示信息标明问题记录和无法计算的图幅；多个错误可以汇总展示，避免用户逐次修复。

“设计条件汇总”工作表增加“折A1”列，项目、提出专业、接收专业、条件明细和总计各层级均实时求和。现有底部“总计”行同时显示：

- 记录总数；
- 总条件张数（现有“图纸数量”列）；
- 折 A1 总数量（新增“折A1”列）；
- 附件总数。

“设计条件明细”工作表本次不增加折 A1 列，继续按一种图幅一行展开。

## 错误处理

折 A1 换算提供可诊断的失败结果，不用 `0` 代替未知图幅。编辑兼容提示与导出错误提示使用同一套合法性判断。

导出服务自身也保留校验边界，即使将来有其他调用方绕过页面预检查，也不能生成折 A1 不完整的工作簿。

## 测试范围

- 固定九项的顺序和系数准确；
- 单图幅、多图幅及数量组合的折 A1 计算准确；
- 未知图幅计算失败，不能静默返回零；
- 编辑器加载未知历史图幅时清空界面图幅、保留数量并给出提示，源对象不变；
- 编辑器只接受固定图幅；
- Excel 导出遇到未知图幅时失败且不生成文件；
- Excel 汇总页包含“折A1”列，各分级行和总计行数值正确；
- 现有多图幅序列化、数据库迁移、备份和 Excel 明细测试继续通过。

## 不在本次范围内

- 不在主列表、日历或编辑弹窗增加折 A1 汇总展示；
- 不迁移或批量改写历史数据库值；
- 不删除数据库中既有的历史图幅选项；
- 不修改 Excel 明细页列结构。
